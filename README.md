# EcomDev — O'quv Markazi To'lovlar Tizimi

O'quv markazi uchun mini to'lovlar hisobi tizimi: o'quvchilar, to'lovlar va oylik qarzdorlarni monitoring qilish uchun veb-ilova.

---

## 🛠 Texnologiyalar

- **Backend:** Node.js, TypeScript, Express.js
- **Ma'lumotlar bazasi:** Supabase (PostgreSQL) + `@supabase/supabase-js`
- **Frontend:** Vue.js 3 (CDN), Mobile-First zamonaviy interfeys
- **Arxitektura:** REST API + SPA (Single Page Application)

---

## 🚀 Loyihani noldan ishga tushirish (Qadam-baqadam)

### 1. Supabase da loyiha yaratish (1 daqiqa)

1. [Supabase](https://supabase.com) ga kiring va bepul yangi loyiha (Project) oching.
2. Chap menyudan **SQL Editor** bo'limiga kiring.
3. Loyihadagi `schema.sql` fayli ichidagi SQL kodini nusxalab, SQL Editor ga qo'ying va **Run** tugmasini bosing:
   ```sql
   -- O'quvchilar jadvali
   CREATE TABLE IF NOT EXISTS students (
     id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
     name TEXT NOT NULL,
     phone TEXT NOT NULL,
     group_name TEXT NOT NULL,
     monthly_amount NUMERIC NOT NULL CHECK (monthly_amount > 0),
     created_at TIMESTAMPTZ DEFAULT NOW()
   );

   -- To'lovlar jadvali
   CREATE TABLE IF NOT EXISTS payments (
     id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
     student_id BIGINT REFERENCES students(id) ON DELETE CASCADE NOT NULL,
     amount NUMERIC NOT NULL CHECK (amount > 0),
     date DATE NOT NULL,
     created_at TIMESTAMPTZ DEFAULT NOW()
   );

   -- RLS sozlamalari
   ALTER TABLE students ENABLE ROW LEVEL SECURITY;
   ALTER TABLE payments ENABLE ROW LEVEL SECURITY;

   CREATE POLICY "Allow all on students" ON students FOR ALL USING (true) WITH CHECK (true);
   CREATE POLICY "Allow all on payments" ON payments FOR ALL USING (true) WITH CHECK (true);
   ```
4. **Project Settings -> API** bo'limiga kiring va quyidagilarni oling:
   - **Project URL** (`https://xyzcompany.supabase.co`)
   - **anon / public key** (yoki service_role key)

### 2. Loyihani sozlash va ishga tushirish

```bash
# 1. Repozitoriyani klonlash
git clone https://github.com/YOUR_USERNAME/ecomdev.git
cd ecomdev

# 2. Bog'liqliklarni o'rnatish
npm install

# 3. Muhit o'zgaruvchilarini sozlash (.env)
cp .env.example .env
```

`.env` faylini ochib, Supabase kalitlaringizni yozing:
```env
PORT=3000
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your-supabase-key-here
```

```bash
# 4. Development rejimida ishga tushirish (hot-reload bilan)
npm run dev

# Yoki build qilib production rejimida ishga tushirish:
npm run build
npm start
```

### 3. Brauzerda ochish

Brauzeringizda quyidagi manzilga kiring:
```
http://localhost:3000
```

## 📡 API Endpoints

### 1. O'quvchilar (Students)
- `GET /api/students` — barcha o'quvchilar ro'yxati
- `POST /api/students` — yangi o'quvchi yaratish
- `PUT /api/students/:id` — o'quvchi ma'lumotlarini o'zgartirish
- `DELETE /api/students/:id` — o'quvchini o'chirish (to'lovlari bilan birga kaskadli o'chadi)

**Talaba yaratish (POST `/api/students`):**
```json
{
  "name": "Ali Valiyev",
  "phone": "+998901234567",
  "group_name": "NodeJS-01",
  "monthly_amount": 600000
}
```

### 2. To'lovlar (Payments)
- `POST /api/payments` — to'lov qo'shish
- `GET /api/payments/student/:id` — berilgan o'quvchining to'lovlari ro'yxati

**To'lov kiritish (POST `/api/payments`):**
```json
{
  "student_id": 1,
  "amount": 400000,
  "date": "2026-10-26"
}
```

### 3. Qarzdorlar (Debtors)
- `GET /api/debtors?month=YYYY-MM` — ko'rsatilgan oy bo'yicha to'liq to'lamagan o'quvchilar ro'yxati va ularning qarz summasi.

## 🔮 Yana 1 hafta vaqt bo'lsa, nimalarni yaxshilagan bo'lar edim (3–5 punkt)

1. **Autentifikatsiya va Role-based Access Control (RBAC):** Supabase Auth yoki JWT asosida administrator va menejerlar uchun login tizimi yaratish, harakatlar tarixini (audit log) yuritish.
2. **Kengaytirilgan ma'lumotlar tahlili va filtrlar:** Guruhlar, o'qituvchilar kesimida qarzlar hisoboti, oraliq sanalar bo'yicha qidiruv, PDF va Excel formatida yuklab olish.
3. **Avtomatlashtirilgan eslatmalar (SMS / Telegram):** Qarzdor o'quvchilarga har oy belgilangan sanada bot yoki SMS-provayder (Eskiz) orqali avtomatik to'lov eslatmasi yuborish tizimi.
4. **Validatsiya va Test qoplamasi:** `zod` kutubxonasi yordamida request payload'larini qat'iy tekshirish hamda Vitest / Supertest bilan to'liq unit va integration testlar yozish.
5. **Docker & CI/CD:** Loyihani to'liq konteynerlash (`Dockerfile`, `docker-compose.yml`) va GitHub Actions orqali avtomatlashtirilgan CI/CD pipelinelarini sozlash.
